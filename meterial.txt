PRODUCT
Actoria is an independent Solana community application presented as a public
register. It supports an overview, quests, token status, advisory governance,
treasury reads, and a field guide. Routes remain
#home / #quests / #stake / #governance / #treasury / #learn.

The Anchor community program records quest participation and advisory votes.
It does not mint or distribute tokens, implement token locks, or execute
treasury spending. No token mint or token symbol is configured.

INTERFACE STRUCTURE
A single linear broadcast: a masthead (mark, wordmark, cluster chip, re-read,
wallet, menu), a sticky ticker strip that carries the six numbered sections,
then full-width bands. Every section opens with a statement band (eyebrow,
oversized headline, deck, actions, proof list) and continues in ruled bands:
a four-beat readout with huge figures, ledger rows with mono indices, ballot
rows with split tally bars, receipt-style statement rows, numbered steps and an
accordion. Section bands carry a ghost index number and hairline rules; nothing
floats as a card. The footer is a status strip with network/session facts and a
large outlined wordmark. On small screens the ticker scrolls horizontally, beats
stack one per row and the drawer carries the section list.
Twitter launch material consists of five posts: one brand statement, one
participation post, one advisory-vote post, one register read, and one guide
note. No post carries a contract address; no token mint exists.
