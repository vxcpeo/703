PRODUCT
Rationum is an independent Solana community application presented as a public
register. It supports an overview, quests, token status, advisory governance,
treasury reads, and a field guide. Routes remain
#home / #quests / #stake / #governance / #treasury / #learn.

The Anchor community program records quest participation and advisory votes.
It does not mint or distribute tokens, implement token locks, or execute
treasury spending. No token mint or token symbol is configured.

INTERFACE STRUCTURE
A split stage: a sticky 42% narrative column carries the brand, a vertical
numbered index of the six sections, the route thesis (kicker, headline, deck,
stats, primary actions), the wallet dock and the colophon. The scrolling 58%
stage carries the route body: readout figures, ledger panels, ballot panels,
meter tiles, receipt rows, steps, checklist and FAQ. On small screens the split
becomes a single column with a horizontally scrollable index strip above the
stage.
Twitter launch material consists of five posts: one brand statement, one
participation post, one advisory-vote post, one register read, and one guide
note, drawn in the same Split Stage / Bubblegum Exchange direction (white ground,
floating white panels, soft pink orbs, Segoe UI semibold). No post carries a
contract address; no token mint exists.
